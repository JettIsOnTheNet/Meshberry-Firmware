# Firmware files

| File | Use |
|---|---|
| `MeshBerry-<version>-TLoRaPager-SX1262-full.bin` | First install: Launcher, or USB at `0x0` |
| `MeshBerry-<version>-TLoRaPager-SX1262-update.bin` | USB update at `0x10000`, keeps your data |
| `MeshBerry-latest-TLoRaPager-SX1262-full.bin` | Latest |
| `SHA256SUMS` | Checksums |

`MeshBerryBold-...` files are the colour firmware (MeshBerry Bold 9000); `MeshBerry-...` files are the two dot-matrix styles.

See the [install guide](../docs/INSTALL.md).
