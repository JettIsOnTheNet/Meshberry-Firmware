# Feature comparison

MeshBerry comes as two firmwares with three looks between them. They share almost everything; this is where they differ, and what each has.

| Feature | Meshberry | Mesherola | MeshBerry Bold 9000 |
|---|---|---|---|
| Firmware file | `MeshBerry-` (both styles in one) | `MeshBerry-` (both styles in one) | `MeshBerryBold-` |
| Switch style without reflashing | Yes, to Mesherola | Yes, to Meshberry | One style |
| Private messages, one conversation per person | Yes | Yes | Yes |
| Delivery status (sent, delivered, not delivered) | Yes | Yes | Yes |
| Public, open (#) and private channels | Yes | Yes | Yes |
| Room servers | Yes | Yes | Yes |
| @ mentions with a name picker | Yes | Yes | Yes |
| Address book, discovered nodes (added by hand) | Yes | Yes | Yes |
| Add people by advert, channel, QR code or NFC tag; write your contact to a tag | Yes | Yes | Yes |
| Message Info (hops, route, signal), Node Info, Trace Path | Yes | Yes | Yes |
| Remote admin of repeaters, rooms and sensors | Yes | Yes | Yes |
| Bluetooth companion for the MeshCore phone app | Yes | Yes | Yes |
| Radar (nodes by bearing and distance) | Yes | Yes | On the map |
| Map from tiles on the SD card | No | No | Yes |
| Emoji | 23 dot pictures; others shown as a box | 23 dot pictures; others shown as a box | About 1,700 in colour |
| Emoji picker with favourites (Shift + Space) | Yes | Yes | Yes, full screen with groups |
| Ring tones | Buzzer tones, per person and per channel | Buzzer tones, per person and per channel | Synthesized instruments, per person and per channel |
| Quick brightness and volume (Shift / Space + wheel) | Yes | Yes | Yes |
| Tips for every setting | Yes | Yes | Yes |
| Dark Screen (always, or by the clock) | Dark dot-matrix | Dark dot-matrix | Dark and light looks |
| Screen colours | 8, plus Auto | 8, plus Auto | Fixed |
| LCD effects (backlight, contrast, streaks) | Yes | Yes | Not applicable |
| Wallpaper from the SD card | No | No | Yes |
| Calendar | Month view | Day list | Month view |
| Tasks, alarm | Yes | Yes | Yes |
| 12 or 24 hour clock, time from GPS | Yes | Yes | Yes |
| WiFi: ten saved networks, Auto by GPS, On When Charging | Yes | Yes | Yes |
| New-firmware check | Yes | Yes | Yes |
| Web interface (messages, contacts, map, files, settings) | Yes | Yes | Yes |
| GPS: On, Off, Power Saver; position sharing | Yes | Yes | Yes |
| Settings, contacts and messages on the SD card | Yes | Yes | Yes |
| Private key export and import | Yes | Yes | Yes |
| Key Lock for a pocket (hold the wheel to unlock) | Yes | Yes | Yes |
| Flip to Mute, Power Saver, Radio Sleep (test) | Yes | Yes | Yes |
